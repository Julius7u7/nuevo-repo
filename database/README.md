# Base de datos

Coloca aquí los archivos relacionados con la base de datos. Ejemplos:

- database/schema.sql — definiciones de tablas
- database/dump.sql — volcado de datos
- database/seed.sql — datos de ejemplo

IMPORTANTE: Si tu base de datos contiene datos sensibles, no la subas a un repositorio público o añade las credenciales en archivos que estén en el .gitignore.
